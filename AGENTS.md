This repository is a NocoBase Solution: `nocoproject/` is the application, `nocoproject-cli/` is the daemon and CLI, and the Chinese product plans and phase documents are under `nocosolution/NocoProject/`. The NocoSolution series guideline and skill are included through the `nocosolution/` submodule. The shared skill is at `.agents/skills/nocosolution`; `.claude/skills/nocosolution` is the Claude Code mirror. The application directory's `.claude/skills/` is generated by `skills sync` and does not belong here.

- Before drafting or revising a plan, changing the skeleton (`trigger`, `run`, `shared/`, or inbox), adding a temporary implementation, or designing cross-Solution integration, read `.agents/skills/nocosolution/SKILL.md` first.
- At the start of work, run `git pull && git submodule update --init --remote --merge`.
- When a situation covered by section 14.2 of the series guideline requires a report, enter `nocosolution/`, update the guideline, commit and push it, then return here and commit the updated submodule pointer.
- State the referenced guideline version in the plan's basis. Generate the web page with `node nocosolution/NocoProject/scripts/build-doc.mjs`; generated pages are not committed.
- Everything written into this repository is in English: code, comments, file headers and markers, Markdown docs, scripts and their messages, test names, commit messages, branch names, and pull request titles, descriptions and review comments. Chinese appears only as product content: the Chinese locale files (`nocoproject/client/locales/`, `nocoproject/server/locales/`), seed and demo data a Chinese-speaking user sees, test fixtures that exercise Chinese input, and keyword lists that match Chinese text. Name a Chinese UI label in English, with its locale key when that helps (`np.issues.new`), instead of quoting the Chinese. Never edit an applied migration only to translate it. The exception is the `nocosolution/` submodule (the NocoSolution repository): its guideline, product plans and phase documents are written in Chinese.
